# Cardiovascular Risk Prediction Model 

## 📌 Project Overview
This project focuses on predicting the risk of cardiovascular disease using machine learning techniques.  
It analyzes patient health data to classify or estimate cardiovascular risk, helping in early detection and preventive decision-making.

---

## 🎯 Objectives
- Analyze cardiovascular health data
- Perform data preprocessing and exploratory analysis
- Build machine learning models for risk prediction
- Compare classification and regression approaches
- Generate insights from model performance

---

## 🧠 Machine Learning Techniques Used
- Data Cleaning & Preprocessing
- Feature Selection
- Classification Models
- Regression Models
- Model Evaluation and Logging
